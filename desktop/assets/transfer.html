First-time Google setup
  1. In Google Cloud Console, create/select a project and enable the Google Drive API.
  2. Configure the OAuth consent screen. If in Testing mode, add your Google account as a test user.
  3. Create an OAuth client of type Desktop app and download its JSON.
  4. Choose that JSON above, then sign in in your usual browser.

Testing-mode Google grants can expire after seven days. The app requests only access to Drive files it creates. Tokens are stored in a private file on this computer.
